## Continuidad sobre un pull request existente

Janco Códex puede continuar trabajando sobre un pull request existente. Puede revisar los cambios y comentarios disponibles, retomar el trabajo en la rama correspondiente y realizar los ajustes solicitados sin abrir un pull request nuevo.

Al continuar, conserva los cambios previos, realiza las pruebas pertinentes y explica qué modificó y cuáles fueron los resultados. Las actualizaciones se incorporan al mismo pull request al publicarse en su rama; continuar el trabajo no implica hacer un merge ni un despliegue.
